## 1. 问题

平台能回答"这张表有哪些字段、什么类型"，但**回答不了"这张表的数长什么样"**。用户想判断一张表能不能用，只能自己去写探查 SQL。

这不是能力缺失，而是**链路断在中间**：

| 环节 | 状态 | 证据 |
|---|---|---|
| 采样 SQL | ✅ 已有 | `platform/dialect/*.py` 的 `sample_sql` |
| 画像落库表 | ✅ 已有 | `storage/models_governance.py:26,143`（`TableProfile` / `TableProfileHistory`） |
| **采样执行器** | ❌ **完全没有** | 全 `src/` 检索 `histogram/percentile/quantile/median` 无命中（唯一命中是 Prometheus 指标） |
| 画像呈现 | ❌ 占位页 + 零图表 | `web/src/pages/placeholders/DegradedPage.tsx`；`@ant-design/charts` 已装但 `web/src` 零 import |

**为什么先做它**：这是全平台唯一"两侧就绪、只缺中间"的能力，且它产出的采样数据后续会被分级验证（FR-M6）复用。

---

## 2. 目标与非目标

**目标**
- 让用户在不开 SQL 客户端的前提下判断一张表的数据形态。
- 让画像结果可留存、可回溯、可对比。

**非目标**
| 项 | 理由 |
|---|---|
| 全表精确统计 | 大表成本不可控；采样是本特性的前提，不是妥协 |
| 跨表/跨列关联分析（如函数依赖、相关性） | 超出本特性范围 |
| 数据质量规则判定 | 属 FR-M5（`05-4`） |
| 引入 `openmetadata-ingestion` 依赖 | 见总纲 §2.3（许可证 + 依赖体积否决） |

---

## 3. 约束

继承总纲 C1~C8，本特性额外约束：

| # | 约束 |
|---|---|
| PC1 | **采样结果必须自带精度标记**：采样的统计值与全量的统计值在语义上不同，两者不得混用或混展示 |
| PC2 | 对业务库**只执行只读语句**；画像作业必须能使用只读账号完整跑通 |
| PC3 | 不得把 `pandas` 从 `dev` extra 提升为运行时依赖（当前 `pyproject.toml:49`） |
| PC4 | 新增代码全部落在 `platform/`（L3），不得修改 `schema/`、`core/`（L1） |

## 4. 用户场景

| 角色 | 场景 | 期望 |
|---|---|---|
| 数据分析 | 第一次接触一张陌生表 | 打开表详情 → 画像 Tab，看到每列空值率、取值分布、枚举样例，判断能否用于报表 |
| 数据分析 | 怀疑某列数据质量有问题 | 看该列直方图与最小/最大值，立刻发现异常区间 |
| 数据平台/DBA | 周期性巡检 | 对比本周与上周画像，发现行数骤降或空值率突增 |
| 数据治理 | 判断某列是否值得分级 | 看样例值与唯一值数，低基数列更适合枚举识别 |
| 任何人 | 数据源不支持采样 | 看到明确原因与替代方案，而不是空白页 |

## 5. 功能需求

### FR-M1 采样与列级画像

| # | 需求 |
|---|---|
| FR-M1.1 | 采样比例按表行数**自动分档递减**，无需用户配置；小表全量、大表降采样 |
| FR-M1.2 | 采样以 **SQL 下推**执行，优先利用库内 `TABLESAMPLE` / 分区裁剪；不支持时退化为随机取模 CTE |
| FR-M1.3 | 行数估算优先读系统表统计信息，**失败才退化为 `COUNT(*)`** |
| FR-M1.4 | 列级统计至少覆盖：行数、空值数/率、唯一值数、最小/最大、均值、标准差、分位数 |
| FR-M1.5 | 分位数优先使用库内近似函数；无近似函数时用精确函数，**结果须记录所用方法** |
| FR-M1.6 | 数值列生成分布直方图，桶数按数据自适应并**有上限** |
| FR-M1.7 | 支持按数据源/库/schema/表三级配置**采样列白名单与黑名单**，以及采样开关 |
| FR-M1.8 | 画像结果写入既有画像表并**保留历史快照**，可查任意历史时点 |
| FR-M1.9 | 画像作业接入既有任务编排（触发方式、并发上限、重试、取消、耗时记录） |
| FR-M1.10 | **每次画像结果须记录采样标记**（全量 / 采样率 / 采样方式），随统计值一同存储（PC1） |

### FR-M2 画像可视化

| # | 需求 |
|---|---|
| FR-M2.1 | 表画像页：表级概览（行数、列数、空值率分布）+ 列级统计列表，列可展开看直方图 |
| FR-M2.2 | 直方图支持"数值分布"与"字符串长度分布"两种口径 |
| FR-M2.3 | 支持按**画像日期**切换历史快照，并能对比任意两次快照的关键指标变化 |
| FR-M2.4 | 画像未采集 / 数据源不支持采样 / 采集失败时，展示明确原因与"立即采集"入口，而非空白 |
| FR-M2.5 | 触发画像前须二次确认，并提示将对目标库执行只读查询 |
| FR-M2.6 | **采样得来的统计值在界面上必须显式标注**（如"基于 10% 采样"），不得呈现为精确值（PC1） |
| FR-M2.7 | 采样表与全量表的统计值不得在同一图表上直接对比，除非图表明确区分两者口径 |

## 7. 验收标准

- **AC-1.1**：对行数 ≤ 阈值的表，采样比例为全量；超过阈值的表按分档自动降采样，且实际采样率可在任务日志中查到。
- **AC-1.2**：对含数值/字符串/日期/空值混合列的表执行画像，**全量表**的空值率与唯一值数与直接查询该表的结果**精确一致**；**采样表**允许偏差，但结果须带采样标记。
- **AC-1.3**：任一列的直方图桶数不超过规定上限。
- **AC-1.4**：使用只读账号可完整跑通一次画像；画像期间对业务库的语句全部为只读。
- **AC-1.5**：连续两次画像后，可查询到两次历史快照及差异。
- **AC-1.6**：分位数结果中记录了所用方法（近似函数 / 精确函数）。
- **AC-2.1**：打开任一张已画像表的画像页，无需跳转即可看到列级空值率与数值分布。
- **AC-2.2**：`supports_sampling=false` 的数据源，画像页显示"该数据源不支持采样"及原因，不报错、不留白。
- **AC-2.3**：切换画像日期下拉，图表与统计值随之切换到对应快照。
- **AC-2.4**：采样表的统计值在界面上有可见的采样标注。

## 8. 边界情况

### 8.1 阻塞设计（必须在本特性设计阶段解决）

| # | 情况 | 期望行为 |
|---|---|---|
| E1 | 数据源不支持 `TABLESAMPLE` | 自动退化为随机取模采样，并在结果中标记采样方式 |
| E2 | 系统表统计信息不可用 | 退化为 `COUNT(*)`，记录降级原因 |
| E3 | 列全为空值 / 唯一值等于行数 | 分位数与直方图标记为不适用，不产生误导性图表 |
| E4 | **采样的唯一值数必然低估** | 结果标记 `sampled=true`；界面标注；禁止与全量值混对比 |
| E5 | 直方图 IQR 为 0（取值高度集中） | 触发退化分桶策略，不产生除零或单桶无意义图 |

### 8.2 运维与展示

| # | 情况 | 期望行为 |
|---|---|---|
| E6 | 表行数为 0 | 画像成功返回空统计，不报错 |
| E7 | 单表列数极多（宽表） | 按列白/黑名单与列数上限裁剪，超限部分标记未采集 |
| E8 | 画像执行中目标表被删除或权限被回收 | 任务失败并给出可操作原因，不重试打爆 |
| E9 | 同一表被并发触发两次画像 | 幂等：后者复用前者结果或排队，不产生重复快照 |
| E10 | 超大型表 | 按 NFR-M1 跳过，并记录跳过原因（可查询"为什么这张表没有画像"） |
