## 1. 问题

血缘是"**已建未接线**"的典型：

| 环节 | 状态 | 证据 |
|---|---|---|
| 表级 + 列级解析 | ✅ 已有（sqlglot） | `platform/lineage/parse.py:46,68` |
| 前端图组件 | ✅ 已实现 | `web/src/components/LineageGraph.tsx`（`@xyflow/react`，含分层布局与 MiniMap） |
| **页面** | ❌ 占位页 | 路由指向 `DegradedPage` |
| **功能开关** | ❌ 默认关闭 | `platform/resilience/feature.py:31` `MOD_LINEAGE=False` |

缺的不是解析能力，而是**解析健壮性**（复杂 SQL 会失败）和**呈现入口**。

---

## 2. 目标与非目标

**目标**：让血缘从"能解析简单 SQL"变成"敢默认开启、复杂 SQL 也能用、有页面可看"。

**非目标**

| 项 | 理由 |
|---|---|
| 引入 `collate-sqllineage` 依赖 | 总纲 §2.3.6：以既有 sqlglot 为主，仅移植"回退 + 超时 + 折叠"的**编排逻辑** |
| 跨数据源血缘、BI/报表血缘 | 超出范围 |
| 存储过程/动态 SQL 的完整解析 | 见 §8 E4 的降级策略 |

---

## 3. 约束

继承总纲 C1~C8，额外：

| # | 约束 |
|---|---|
| LC1 | 单条 SQL 解析必须有**超时**，超时不得阻塞整体任务 |
| LC2 | **解析失败不得导致整表血缘缺失**：单条失败只影响该条 |
| LC3 | 血缘不可用时按 C6 降级展示（显示"不可用"而非报错或空白） |

---

## 4. 用户场景

| 角色 | 场景 | 期望 |
|---|---|---|
| 数据平台/DBA | 评估改一张表的影响面 | 打开血缘页，展开下游节点逐级下钻，看到受影响的表与字段 |
| 数据分析 | 某个指标字段是哪来的 | 切换列级血缘，看到源列 → 目标列的链路 |
| 数据平台/DBA | 部分 SQL 解析失败 | 看到"已解析 N 条，M 条失败"及失败原因清单，其余血缘照常可用 |

## 5. 功能需求

| # | 需求 | 上游来源 |
|---|---|---|
| FR-M4.1 | SQL 解析支持**多解析器依次回退**，并有单条解析超时，超时不阻塞整体任务 | `lineage/parser.py:493-641` |
| FR-M4.2 | CTE 与临时中间表不产生孤立节点，折叠为"源列 → 目标列"直连边 | `lineage/sql_lineage.py:366-415` |
| FR-M4.3 | 血缘页挂载既有图组件，支持节点展开下钻、缩放、表级/列级切换 | 复用 `web/src/components/LineageGraph.tsx` |
| FR-M4.4 | 解析失败的语句**单独记录原因并可查询**，不导致整表血缘缺失 | LC2 |
| FR-M4.5 | 血缘功能开关转为默认开启；解析不可用时按 C6 降级展示 | `platform/resilience/feature.py:31` |

## 6. 非功能需求

| # | 需求 |
|---|---|
| NFR-M5 | 产出既有 Prometheus 指标（解析条数、失败率、解析耗时分布） |
| NFR-M6 | 既有单测不得失败；L1 文件不得被修改 |
| LC-N1 | 血缘图在节点数超过阈值时须有降级呈现（分页/分层加载/聚合节点），不得一次性渲染导致页面卡死 |

---

## 7. 验收标准

- **AC-4.1**：构造含 CTE、子查询、别名、跨库引用的 SQL 集合，血缘边覆盖率相对现状提升，且**不产生孤立中间节点**。
- **AC-4.2**：注入一条无法解析的 SQL，其余 SQL 血缘正常产出，且失败原因可查询。
- **AC-4.3**：单条 SQL 解析超时后，任务在可控时间内完成，不挂起。
- **AC-4.4**：血缘页可正常打开并完成下钻与表级/列级切换。
- **AC-4.5**：功能开关默认开启后，不可用的场景显示降级提示而非报错（C6）。
- **AC-4.6**：超大规模血缘图（节点数超阈值）按 LC-N1 降级呈现，页面不卡死。

## 8. 边界情况

### 8.1 阻塞设计

| # | 情况 | 期望行为 |
|---|---|---|
| E1 | SQL 含 CTE / 派生表 | 折叠为直连边，不产生孤立中间节点 |
| E2 | SQL 含临时表 | 同上；无法归属时标记为不可解析并记录（LC2） |
| E3 | 单条 SQL 解析超时 | 跳过并记录，任务继续（LC1） |
| E4 | 动态 SQL / 存储过程内 SQL | 标记为不可解析并记录原因；不猜测、不产生错误边 |

### 8.2 展示

| # | 情况 | 期望行为 |
|---|---|---|
| E5 | 血缘图中存在环（循环依赖） | 可渲染且不无限递归；环上有视觉标识 |
| E6 | 节点数极多 | 按 LC-N1 降级呈现 |
| E7 | 上游/下游实体已被删除 | 边标记为失效，可清理；不显示为正常节点 |
| E8 | 列级血缘中某列无法确定来源 | 标记为未知来源，不伪造边 |
